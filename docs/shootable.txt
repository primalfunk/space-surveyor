SHOOTABLE → PICKUP DROP SPEC (v1)
Symbolic Drop Mapping for Core Gameplay Loop

This document defines which shootable archetypes may drop which pickup types.
The mapping is symbolic, not merely mechanical.
Each shootable embodies a stance toward meaning and therefore may only yield
pickups aligned with that stance.

This spec is authoritative for balance, tone, and future expansion.

----------------------------------------------------------------
GLOBAL DROP RULES (LOCKED)
----------------------------------------------------------------

1) No shootable may drop all pickup types.
2) No pickup type may be dropped by all shootables.
3) Fuel is exceptional and may be dropped sparingly by multiple shootables.
4) Only one pickup type may be PRIMARY per shootable.
5) Secondary drops must be rarer and feel incidental, not farmable.
6) Loss, decay, or risk must exist in every non-Fuel drop loop.

----------------------------------------------------------------
PICKUP TYPES (REFERENCE)
----------------------------------------------------------------

Fuel       — Survival / continuation
Material   — Accumulation / labor
Fragments  — Loss / partial meaning
Signal     — Observation / legibility
Impulse    — Intervention / escalation
Relic      — History / residue
Noise      — Temptation / amplification

IMPLEMENTATION NOTE (v1)

- Fuel and Material retain current gameplay effects.
- Other pickup types are introduced as drop categories but have no gameplay effect yet.

----------------------------------------------------------------
SHOOTABLE TYPE: ASTEROID
----------------------------------------------------------------

Symbolic role:
Raw matter. Pre-meaning existence. Mundane labor.

Primary drop:
- Material (common)

Secondary drops:
- Fuel (uncommon, small amounts)

Forbidden drops:
- Signal
- Impulse
- Relic
- Noise

Notes:
Asteroids are boring on purpose.
They are the only reliable long-horizon progression source.
They should never feel mysterious.

----------------------------------------------------------------
SHOOTABLE TYPE: SHARD
----------------------------------------------------------------

Symbolic role:
Fragmentation. Translation loss. Partial truths.

Primary drop:
- Fragments (common, multiple per object)

Secondary drops:
- Material (rare, via imperfect recombination)

Forbidden drops:
- Signal
- Impulse
- Relic
- Noise

Notes:
Shooting shards always produces loss.
Fragments may decay, drift, or combine inefficiently.
Precision reduces loss but never eliminates it.

----------------------------------------------------------------
SHOOTABLE TYPE: NODE
----------------------------------------------------------------

Symbolic role:
Observation without reply. Registration.

Primary drop:
- Signal (guaranteed)

Secondary drops:
- None (by default)

Optional rare secondary (late game only):
- Fragment (very rare, symbolic only)

Forbidden drops:
- Material
- Impulse
- Relic
- Noise

Notes:
Nodes are informational, not extractive.
Shooting a node should feel like interrupting a watcher.
Signal effects must decay quickly.

----------------------------------------------------------------
SHOOTABLE TYPE: VOLATILE CORE
----------------------------------------------------------------

Symbolic role:
Intervention. Escalation. Forcing outcomes.

Primary drop:
- Impulse (guaranteed, immediate effect)

Secondary drops:
- Fuel (situational, burst-style)

Forbidden drops:
- Material
- Signal
- Relic
- Noise

Notes:
Impulse effects are dramatic and destabilizing.
Volatile Cores must never be safe to farm.
Their value is entirely contextual.

----------------------------------------------------------------
SHOOTABLE TYPE: WRECKAGE
----------------------------------------------------------------

Symbolic role:
History. Residue. What remains after intent is gone.

Primary drop:
- Relic (rare, conditional on gentle destruction)

Secondary drops:
- Fragments (uncommon, symbolic)
- Material (very rare, degraded)

Forbidden drops:
- Signal
- Impulse
- Noise

Notes:
Overkill destroys value.
Wreckage rewards restraint and patience.
Relics must feel precious and fragile.

----------------------------------------------------------------
SHOOTABLE TYPE: LURE
----------------------------------------------------------------

Symbolic role:
Temptation. Over-communication. Making noise.

Primary drop:
- Noise (guaranteed)

Secondary drops:
- None directly

Indirect effects:
- Temporarily increases drop rates of other shootables
- Increases anomaly / hazard density elsewhere

Forbidden drops:
- Material
- Fuel
- Fragments
- Signal
- Impulse
- Relic

Notes:
Noise does nothing by itself.
Its value is meta-contextual and dangerous.
Lures should always feel optional and suspicious.

----------------------------------------------------------------
CROSS-CHECK MATRIX (SUMMARY)
----------------------------------------------------------------

Asteroid      → Material, Fuel
Shard         → Fragments, (rare) Material
Node          → Signal
Volatile Core → Impulse, (situational) Fuel
Wreckage      → Relic, Fragments, (very rare) Material
Lure          → Noise

----------------------------------------------------------------
DESIGN AXIOMS (NON-NEGOTIABLE)
----------------------------------------------------------------

1) Material is earned through time, not cleverness.
2) Knowledge (Signal) cannot be stockpiled.
3) Power (Impulse) always destabilizes.
4) History (Relic) is easy to destroy.
5) Noise amplifies everything except understanding.
6) Loss is not a failure state; it is the language.

END OF SPEC
